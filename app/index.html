MV3 Replay: local manifest analyzer

This page runs entirely on your machine against a local server bound to 127.0.0.1. Selecting a file only reads it in your browser; only the parsed manifest JSON is sent to the local analyzer. Nothing is uploaded, stored, tracked, or sent to any other destination.

Keyboard shortcuts (ignored while a text field, textarea, or select has focus): I focuses the inspect manifest file input, C focuses the compare previous-release file input, S or / focuses the visible findings search box, and Escape clears the workspace.

10-minute tester session

Try the workflow without sharing private data

  1. Run the built-in analysis example and inspect the suggested test lanes.
  2. Analyze one local MV3 manifest and mark any checks you can complete.
  3. Compare two releases if available, then note what was useful or confusing.

Do not include source code, account details, extension names, private URLs, or personal information in feedback. The downloaded template stays on your device.
